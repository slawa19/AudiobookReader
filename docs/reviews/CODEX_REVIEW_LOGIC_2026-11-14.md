### Непокрытые пути: что добавлено и что сочтено экзотикой

Добавлено (пути живого читателя): одностраничная книга → полка; сноска у границы предложения; скорость с проверкой
движения; старт внутри блока → смена профиля; выбор абзаца → изменение высоты панели; «до конца главы» из листа и
в последней главе; конец книги → повтор последнего абзаца; срок таймера в `waiting`; пауза → листание → команды
извне; ошибка → листание/шрифт/«Закрыть»; конец книги → листание → «Закрыть»; истёкший таймер → «Читать отсюда»;
очистка → скачивание; проба → смена модели → проба.

Экзотика для подставного контроллера (записано как проверка при замене, А§9 и README прототипа): позднее
завершение старой асинхронной операции после смены сеанса; поздний ответ старого запроса после нового места в
`waiting`; сохранение паузы при смене профиля без готового звука; частичное скачивание → удаление или смена профиля
→ поздний результат. Обновление остатка минут без постороннего перестроения экрана — экзотика (виден только на
панели, ошибка перестроения на поведение не влияет).
