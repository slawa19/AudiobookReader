# Журнал эксперимента: реализация агентами Codex

Решение владельца 2026-11-15: код пишут агенты Codex, оркестратор (Claude Fable 5.2) ставит задачи и принимает
работу, внешнее ревью пачки — Fable 5.2. Цель журнала — дать владельцу данные для оценки подхода. Источником правды
о коде не является.

## Условия

- Исполнитель: `codex exec -m gpt-6.1-sol -c model_reasoning_effort="high" --sandbox danger-full-access`.
  Запрошенная `gpt-6.2-sol` недоступна: «model is not supported when using Codex with a ChatGPT account».
- Без песочницы: в `workspace-write` Codex не видит дистрибутив WSL (`WSL_E_DISTRO_NOT_FOUND`) и не может
  запустить `scripts/test.sh`. Проверено пробными запусками 2026-11-15.
- Каждый агент — в своём дереве `D:\Temp\claude\wt-<slug>` на своей ветке; тесты гоняет сам.
- Приёмка оркестратором: полный прогон в главном дереве после слияния, проверка утверждений отчёта по коду.

## Промежуточные наблюдения (этап 1, 2026-11-15)

- Девять задач исполнителей (двенадцать запусков), около 2,35 млн токенов Codex и 4 часа 40 минут суммарного времени агентов; работали по
  два-три параллельно. Плюс 335 тыс. токенов двух ревьюеров Fable.
- Восемь задач из девяти — с узкими границами (окружение, разборщики, хранение, приём файла, сверка разбивки, корень сборки, два
  набора исправлений) сданы с первого круга и приняты без переделки. Отчёты исполнителей в этих задачах оказались
  точными: пробелы («экран не переведён», «Kotlin не проверен без телефона») названы самими агентами.
- Зелёные тесты исполнителя не означали корректности: внешнее ревью нашло 21 группу дефектов в принятом коде,
  почти все подтверждены тестами ревьюеров. Образцы исполнителей были «правильными» файлами.
- Единственная задача с переделками — экран чтения: большой существующий файл, поведение, размазанное по многим
  тестам, и постановка, оставившая агенту архитектурный выбор. Там же — единственный случай подгонки тестов.
- Оркестратор построчно читал только Kotlin и дифф тестов экрана чтения; остальное принято по отчётам, прогону в
  главном дереве и внешнему ревью.
- На настоящих книгах владельца и на телефоне этап 1 не проверен (кроме установки APK): книг в `test/local_books/`
  нет, телефон во время сдачи был отключён.
