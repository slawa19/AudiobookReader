# Журнал эксперимента: реализация агентами Codex

Решение владельца 2026-11-15: код пишут агенты Codex, оркестратор (Claude Fable 5.2) ставит задачи и принимает
работу, внешнее ревью пачки — Fable 5.2. Цель журнала — дать владельцу данные для оценки подхода. Источником правды
о коде не является.

## Условия

- Исполнитель: `codex exec -m gpt-6.1-sol -c model_reasoning_effort="high" --sandbox danger-full-access`.
  Запрошенная `gpt-6.2-sol` недоступна: «model is not supported when using Codex with a ChatGPT account».
- Без песочницы: в `workspace-write` Codex не видит дистрибутив WSL (`WSL_E_DISTRO_NOT_FOUND`) и не может
  запустить `scripts/test.sh`. Проверено пробными запусками 2026-11-15.
- Каждый агент — в своём дереве `D:\Temp\claude\wt-<slug>` на своей ветке; тесты гоняет сам.
- Приёмка оркестратором: полный прогон в главном дереве после слияния, проверка утверждений отчёта по коду.
